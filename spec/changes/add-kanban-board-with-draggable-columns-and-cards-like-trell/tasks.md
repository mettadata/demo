# Tasks for add-kanban-board-with-draggable-columns-and-cards-like-trell

## Batch 1 (no dependencies)

### Task 1.1: Create the kanban store with state management, mutations, and localStorage persistence
- **Files**: `src/lib/stores/kanban.ts` (create)
- **Action**: Implement the full kanban store module. Define `KanbanColumn`, `KanbanState`, `ResolvedColumn`, and `ViewPreference` types. Create the `kanbanState` writable store that loads from localStorage key `kanban-state` on init (falling back to three default columns: "To Do", "In Progress", "Done"). Create the `viewPreference` writable store backed by localStorage key `view-preference` (default `'list'`). Create the `kanbanBoard` derived store that combines `kanbanState` and `todos` to resolve `cardIds` into full `Todo` objects via a `Map` lookup. Implement mutation functions: `addColumn(title)` (rejects empty strings, appends column with `crypto.randomUUID()` id), `renameColumn(columnId, title)` (rejects empty strings), `deleteColumn(columnId)` (throws if last column, moves cards to first remaining column), `moveColumn(columnId, newIndex)`, and `moveCard(todoId, targetColumnId, targetIndex)` (handles both cross-column moves and within-column reordering). Implement `syncWithTodos` inside a `todos.subscribe()` callback that appends new todo IDs to the first column and removes orphaned card IDs from all columns. Persist `kanbanState` to localStorage on every subscription fire. Wrap all `localStorage.setItem` calls in try/catch with `console.warn`, matching the pattern in `todos.ts`.
- **Verify**: Run `npx vitest run src/lib/stores/kanban.test.ts` after Task 1.2 is complete. For immediate verification, confirm the file compiles: `npx tsc --noEmit src/lib/stores/kanban.ts` or run `npm run check`.
- **Done**: The module exports `kanbanState`, `kanbanBoard`, `viewPreference`, `addColumn`, `renameColumn`, `deleteColumn`, `moveColumn`, `moveCard`, and all types. Default initialization creates three columns. Sync with todos adds new cards to the first column and prunes orphans. All mutations persist to localStorage.

### Task 2.2: Create the KanbanCard component with drag-and-drop and accessibility
- **Files**: `src/lib/components/KanbanCard.svelte` (create)
- **Action**: Create a Svelte component accepting props: `todo: Todo`, `columnId: string`, `columnTitle: string`. Render the card with `draggable="true"`, `role="listitem"`, `tabindex="0"`, `aria-grabbed="false"`, and `aria-label="{todo.text} in {columnTitle}"`. Display the todo title, a truncated description preview if present, and a visual priority indicator. On `dragstart`: set `dataTransfer.setData('text/plain', todo.id)`, set `dataTransfer.effectAllowed = 'move'`, update `aria-grabbed` to `"true"`, and add a dragging CSS class (e.g., reduced opacity). On `dragend`: reset `aria-grabbed` to `"false"` and remove the dragging class. Implement keyboard movement: on `keydown`, Space/Enter activates a "move mode" (toggle a local boolean), arrow left/right in move mode dispatches a custom `moveCard` event with direction, Enter in move mode confirms. Style the card with Tailwind: background, padding, rounded corners, shadow, and a left-border color for completed status.
- **Verify**: Run `npm run check`. Visually confirm the card renders todo data, is draggable, shows opacity change during drag, and has correct aria attributes in the DOM inspector.
- **Done**: The card is draggable, displays todo title and completed status, sets dataTransfer on dragstart, updates aria-grabbed during drag, supports keyboard activation for movement, and is styled consistently with the app.

### Task 2.3: Create the KanbanColumn component with drop zone and column header actions
- **Files**: `src/lib/components/KanbanColumn.svelte` (create)

Render a header with the column title (double-click to edit inline -- toggle an input field, reject empty strings, call `renameColumn` on confirm/blur) and a delete button (call `deleteColumn`, catch the error if it is the last column and show a warning message). On `drop` read the `todoId` from `dataTransfer`, call `moveCard(todoId, column.id, dropIndex)`, and remove the highlight. Show a card count in the column header.
- **Verify**: Run `npm run check`. Load the app with the kanban view, confirm columns render with headers, cards appear inside, drag a card over a column to see the highlight, and drop it to move.
- **Done**: The column renders its title (editable on double-click), a delete button, a card count, all its cards via KanbanCard, and acts as a valid drop zone with visual feedback and correct drop index calculation.
